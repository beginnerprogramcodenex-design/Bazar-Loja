# Bazar — edição pelo próprio site

## Como publicar
1. Extraia este ZIP.
2. No repositório GitHub `Bazar-Loja`, envie e substitua `index.html`, `admin.html`, `styles.css` e `app.js` na raiz.
3. Faça Commit changes e aguarde o GitHub Pages atualizar.
4. Abra `https://beginnerprogramcodenex-design.github.io/Bazar-Loja/admin.html`.

## Como editar sem mexer no código
- Em **Produtos e estoque**, cadastre a roupa, escolha categoria, informe preço e quantidade e, se quiser, selecione a foto.
- Em **Configurações**, altere o nome da loja, o slogan, carregue a logo e salve.
- Para ajustar uma roupa já cadastrada, use **Editar**. Para ajustar só a quantidade, use **Ajustar**.
- Use **Exportar backup** para guardar uma cópia dos dados.

## Limitação importante desta versão
Este projeto está hospedado no GitHub Pages e ainda não tem servidor/banco de dados. Produtos, fotos, logo e pedidos ficam no armazenamento do navegador e dispositivo usados para cadastrar. Isso significa que não sincronizam automaticamente com outros dispositivos nem com os navegadores dos clientes. Para uma loja pública em que as alterações apareçam para todos, é necessário conectar um backend com banco de dados e armazenamento de imagens, além de login administrativo seguro.
